Chapter 4: Quadratic Equations
Learning objectives: after this chapter you should be able to solve a quadratic equation by factorisation, completing the square and the quadratic formula.
Example 4.1 Solve x^2 - 7x + 12 = 0. Solution: the equation factors as (x - 3)(x - 4) = 0, so x = 3 or x = 4.
Theorem 4.2 A quadratic equation ax^2 + bx + c = 0 has real roots if and only if b^2 - 4ac >= 0.
