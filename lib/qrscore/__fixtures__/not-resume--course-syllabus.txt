B.Tech Computer Science - Syllabus, Semester 3
Course code CS201: Data Structures. Credits: 4. Topics: arrays, linked lists, stacks, queues, trees, graphs, sorting and searching.
Course code CS203: Discrete Mathematics. Credits: 3. Topics: logic, sets, relations, functions, combinatorics.
Course code CS205: Computer Organisation. Credits: 3. Reference books: Morris Mano, Hennessy and Patterson. Evaluation: internal 30 marks, end semester 70 marks. Attendance of 75 percent is compulsory for appearing in the examination at the university.
