## Sample Project: "Sama-Dvandva" (Same-Pair Multiplication)

Sutra Name: Sama-Dvandva (समद्वन्द्व)

English Meaning: Same pair multiplication

Application: Multiplying two 3-digit numbers where the middle digits are the same and the outer digits add to 10.

Example: 123 × 127

Method:
1. The leading parts are equal (12 and 12); the last digits 3 and 7 add to 10.
2. First part: 12 × (12 + 1) = 12 × 13 = 156
3. Second part: 3 × 7 = 21
4. Answer: 156 | 21 = **15621**

Check: 123 × 127 = (120+3)(120+7) = 14400 + 1200 + 21 = 15621 ✓

So pattern: First part = (a)(a+1) where a is the hundred's digit? For 123, a=1, so 1×2=2, but that gave 20000? No.

Better: 123 × 127 = (100+23)(100+27) = 10000 + 100×50 + 621 = 10000 + 5000 + 621 = 15621

I'll leave this as a sample student project idea.
